# 需求 PRD（拆 feature 的依据）

本文件是**需求级**文档。输入只有一句话或不完整时，先用 `aiassitrequreimentdev-brainstorm` 探方向，再用 `aiassitrequreimentdev-grill` 补齐，最后由产品技能落盘。据此决定开一个还是多个 feature；拆分结论见同目录 `split.yaml`。

每个 feature 目录里还有自己的 `prd.md` / `spec.yaml`（切片合同，含可执行 `UJ*`/`FR*`/`NFR*`/`S*`/`E*`/`A*`）。小需求若只做一个 feature，可跳过本目录，直接在 `features/<id>/prd.md` 写完整切片合同。
