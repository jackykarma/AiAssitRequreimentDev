# 团队约束

本文件由人维护。自动流程不得覆盖。

- feature id / 目录名：`FEAT-<序号>-<kebab名称>`（例如 `FEAT-001-move-album`）。需求 id / 目录名：`REQ-<序号>-<kebab名称>-<YYYYMMDD>`（例如 `REQ-001-move-album-20220305`）。一条需求可对应多个 feature，用 `requirementId` 关联。
- 轻路径仅用于单模块缺陷或已有验收的行为修正。
- 新能力、跨领域、状态机或对外契约走全路径。
- Review 争议裁决须留下 `resolution.rationale`。
