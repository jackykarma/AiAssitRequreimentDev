# 视觉探索清单（仅 `visual.baseline: custom`）

`ui-kit` / 已注册 research kit（`painless` / `midoo` 等，见 `research/ui-kits/catalog.yaml`）路径**不要**用本文另起色板。本文是 custom 自由发挥时的精简检查单（吸收公开移动端/通用 UI 习惯，非外部 skill 全量拷贝）。动效仍建议对齐 `research/ui-kits/MOTION.md`。

## 何时用

人选 `custom` 且 `notes` 已说明为何不用 kit → 做 `prototype/ux/` 前扫一遍。

## 布局与触控

- 主操作落在拇指易达区（屏下约 1/3）；次要操作可上移
- 间距优先 4/8 网格；可点目标建议 ≥ 44×44 CSS px
- 单屏信息层级 ≤ 3；主标题 / 正文 / 辅助勿超过 4 个字号、2 个字重族
- 列表与表单：先内容后装饰；避免首屏堆统计条、多枚徽章

## 色彩与材质

- 主色占比克制（常见 60 中性 / 30 辅色 / 10 强调）
- 对比度：正文与底建议 ≥ 4.5:1；勿只靠颜色表达状态
- 避免默认「AI 紫粉渐变」除非品牌明确要求
- 毛玻璃/阴影服务层次，不替代信息结构

## 反馈与动效

- 每个主操作有即时反馈（按下态 / loading / 成功或失败）
- 动效短、可取消；尊重 `prefers-reduced-motion`
- 高峰体验与结束态清晰（Peak-End）：成功收束比过程炫技更重要

## 交付前自检

- [ ] 无 emoji 当图标（用 SVG）
- [ ] 可点击元素有明确指针/按下态
- [ ] 键盘/读屏：焦点可见；交互控件有语义
- [ ] 窄屏（约 375）文字不裁切；长标签可换行或 `+n` 展开
- [ ] `ux.yaml` 的 `IR*` 与可点通原型一致；`acceptance` 已映射

## 禁止

- 把本清单当第二套事实源覆盖 `spec.yaml`
- 在 `baseline: ui-kit` 时引入本文色板/字体替换 kit
- 未人选就写 `custom`，或 `custom` 却空 `notes`
