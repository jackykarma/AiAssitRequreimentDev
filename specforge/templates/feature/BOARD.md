# Feature 共仓看板

各角色共享本目录下的产物：只写自己的文件，其余只读。

启动时先选角色，再确认全量/轻量路径。不要增加对话草稿类临时文件。

| 文件 | 说明 | 状态 |
| --- | --- | --- |
| `prd.md` | 产品 PRD（给人） | 模板 |
| `prototype/index.html` | 产品 HTML 原型（给人） | 模板 |
| `spec.yaml` | 结构化规格（给 Agent/门禁） | 模板 |
| `ux.yaml` | 交互视觉 | 模板 |
| `tech.yaml` | 技术方案 | 模板 |
| `tasks.yaml` | 任务图 | 模板 |
| `review.yaml` | 代码评审 | 模板 |
| `evidence.yaml` | 测试证据 | 模板 |
| `deploy.yaml` | 部署清单 | 模板 |
